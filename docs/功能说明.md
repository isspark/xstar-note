# XStar 笔记 · 功能说明

> Git 驱动的移动笔记本：管理多个 Git 仓库，浏览、阅读、编辑 Markdown 与各类文本/代码文件，并直接同步回远程；另附独立于 Git 的本地 TODO（任意层级树 + 内置分类系统标签）。

---

## 1. 整体架构与导航

- **首页模式**：设置页可选「默认仓库」「TODO」「仓库 + TODO」「TODO + 仓库」。两种组合模式可自定第一页，向左滑切换到另一页；无默认仓库时仍进入仓库管理。
- **首页导航**：抽屉首项统一为「首页文档」，副标题显示当前首页模式/默认仓库；点击返回配置的首页，不再固定进入默认仓库。
- **手势优先级**：组合首页的普通横滑用于页面切换，左边缘右滑优先打开抽屉；首页启动路由会移除仓库管理回退项，避免系统边缘返回误滑到仓库管理。
- **左侧抽屉导航**（屏幕宽度约 2/3）：
  - 通过从屏幕左缘右划、或点击页面顶部 ☰ 打开；
  - 抽屉内：当前默认仓库（点击直达）、仓库管理、TODO、设置；
  - 抽屉打开时按系统返回只关闭抽屉，不退出页面。
- **统一顶部栏**：所有页面顶部为品牌渐变标题栏；标题与描述同一行，仅用字号/字重/透明度区分；高度统一为 52dp，单行省略。
- **统一按钮风格**：主按钮（`FilledActionButton`）、描边按钮（`OutlinedActionButton`）统一高度/圆角/配色；悬浮按钮统一为**圆形 `XStarFab`**，颜色全部取自当前主题 `colorScheme`，切换深浅色或动态取色时自动跟随。
- **主题设置**：跟随系统 / 浅色 / 深色，以及 Material You 动态取色开关，实时生效并持久化。

## 2. 仓库管理

- 添加仓库：名称（可选）、远程地址、托管平台（GitHub / Gitee / GitLab 分段选择）、用户名、Access Token（支持明文切换）、默认分支；克隆成功即入库。
- 添加成功自动**设为默认仓库并进入浏览**。
- 卡片操作（⋮ 菜单）：
  - **同步仓库**（先拉取再推送）
  - **拉取更新**
  - **推送修改**
  - **删除仓库**：带确认框，删除本地克隆的全部文件并清除本机凭证，不影响远程仓库。
- **设为默认**：卡片右上角星标，点击设为默认并打开；启动时直接进入默认仓库。
- 同步状态徽标：已同步 / 有未推送修改 / 同步中 / 同步出错；忙碌时卡片底部显示进度条。

---

## 3. 文件浏览

- 目录树浏览：目录在前、名称排序；chip 风格面包屑可点击跳转；下拉刷新。
- 文件行按类型显示**彩色矢量图标**，展示大小/类型。
- 行尾 ⋮ 菜单：
  - **重命名** 文件/目录
  - **删除** 文件/目录（目录连子内容一并删除）
  - 上述修改均：写工作区 → git stage + commit → 有令牌自动 push 同步。
- **新建 Markdown 文件**（右下角圆形 ＋）：输入文件名 + **点选**存放目录（根目录 / 当前目录 / 当前目录下子目录），创建后自动 git 提交并推送，并直接进入编辑。
- 图片（png/jpg/jpeg/gif/webp/bmp/svg）点击全屏暗色预览。
- 文件打开类型支持：
  - **Markdown**（.md/.markdown）：渲染阅读 + 编辑 + 文档导航
  - **drawio**（.drawio/.dio）：图形预览
  - **代码/脚本**：.sh、.bat、.cmd、.ps1、py/go/java/kt/js/ts/sql/json/xml/yaml/toml/ini/html/css…及 Dockerfile/Makefile 等，等宽字体纯文本打开并可编辑
  - **纯文本**：.txt/.log/.csv 等

## 4. Markdown / 文本阅读与编辑

- **阅读**：Markdown 渲染（含任务复选框显示）、图片相对路径自动改写为本地文件加载。
- **编辑**（右下角 ✏️ 圆形按钮）：整页编辑，键盘弹出时编辑区自动上移到键盘上方；顶栏 ✓ 保存 / ✕ 放弃。
- **保存同步 Git**：写回文件（尽量沿用原文件编码）→ 重建文档 → 本地 commit → 有令牌自动 push；无令牌/推送失败则本地已提交并把仓库标记为“有未推送修改”，可稍后到仓库管理同步。
- **文档导航**（仅 Markdown，右下角圆形 📖）：解析 `#~######` 章节为列表，按层级缩进；点击定位滚动到对应标题。
- **编码选择**：Markdown 与代码/文本阅读页右上角显示“编码：自动”胶囊，点击可手动选择 UTF-8 / GBK / GB18030 / Big5 / UTF-16LE / UTF-16BE / ISO-8859-1 / US-ASCII，立即按所选编码重读；默认自动探测（BOM → UTF-8 校验 → UTF-16 启发 → GBK 兜底），解决 .bat 等乱码问题。
- 阅读页不再自动提取文档 TODO（打开 MD 不写入额外 TODO 数据）。

## 5. 独立 TODO（不绑定 Git）

本地 TODO 使用**扁平条目 + 自由分类标签 + 开始/截止时间**，默认按分类展示，也可隐式切换到月历。

### 5.1 条目与时间

- 所有 TODO 都是平级条目，不再维护父子树；v4 升级时保留所有原节点并自动扁平化。
- 编辑器支持标题、备注、可选**开始日期/时刻 + 截止日期/时刻**、分类标签；两端时间可独立设置或清除，截止不得早于开始。
- 新建/编辑使用**独立页面**（不再使用弹框）：标题/备注使用输入框自身标签，时间/分类使用上方小标题；页面沿用统一渐变顶栏、主题输入框与全宽主按钮。
- 未完成且超过截止时刻的条目以红色"已过期"高亮；列表按未完成优先、截止时间升序排列。
- 整行点击勾选/取消完成；行尾 ⋮ 提供编辑与删除。

### 5.2 分类系统与标签

- **分类系统** = 一组带颜色的分类标签，App 内置三套：**类型**（故事/需求/任务，随层级概念）、**重要 × 紧急**（四象限）、**状态**（待办/进行中/已阻塞/已完成）。
- **类型已作为标签**：内置"类型"系统下可自建/改名/改色/删除类型，行内以**彩色胶囊**展示，编辑时类型系统单选。
- 每条 TODO 可同时打多套系统内多个标签（其它系统可多选）；编辑条目时按系统点选。
- 分类管理页（TODO 页右上角 Tune）：启用/停用系统；**内置与自定义系统的分类都可改名/改色/删除/新增**；系统名/整个系统删除仅限自定义系统。

### 5.3 视图与筛选

- **按分类（默认）**：页面不常驻筛选栏；右下角筛选浮动按钮统一设置分类系统、系统内分类和完成状态。
- 分类卡片使用**分类色标题区 + 内容淡彩**；颜色在分类管理中设置。同一条目打多个同系统标签时可出现在多个分类卡片；另有"未分类"卡片。
- **日历视图**：顶栏仅显示一个无文字切换图标（分类⇄日历）；任务有起止时间时，会出现在开始到截止日期区间内的每天。月历提醒点直接使用**当前分类系统的分类颜色**，同一天有多个分类时并排显示多个色点（最多 4 个）；未分类为灰色。
- 导入/导出收进顶栏 ⋮，减少常驻操作按钮。
- 分类区域只保留外层轻度圆角，内部 TODO 使用直角分隔；筛选与新增统一为相同尺寸、圆形和主主题色的 `XStarFab`。
- 顶栏副标题实时显示 `x 项待办 · y 已完成`。

### 5.4 导入导出

- **导出到仓库**：生成平级 `- [ ]` / `- [x]` 清单；开始/截止分别以 `<!-- xstar-start:epoch -->` / `<!-- xstar-due:epoch -->` 元数据保留。
- **从仓库导入**：解析 Markdown 任务、备注与 XStar 起止时间元数据，按标题去重并入本地。

## 6. 数据与底层

- 本地 Room 数据库（v6）：仓库、文档级 TODO、本地扁平 TODO（`todo_nodes`，含 `startAt` / `dueAt`）、分类系统（`category_systems` / `categories` / `node_categories`）；v5→v6 无损增加可空开始时间。
- 安全存储：仓库令牌经加密存储；删除仓库时一并清除。
- Git 能力（JGit）：clone / pull(reb) / push / add+update stage / commit / 文件读写。
- 文本编码：读取自动探测，保存沿用原编码。
- 偏好设置：主题模式、动态取色、默认仓库 ID（SharedPreferences 持久化）。
